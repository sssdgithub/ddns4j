# 凭据一次性下发，不落库

BYOC 要求控制面不保存用户云厂商凭据，但新端点仍需要拿到凭据才能执行任务。v1 采用一次性下发：控制台把凭据经 TLS 转发给在线端点，单次有效、短 TTL（建议 60 秒）、仅内存、不落库、不落日志；同时保留本地配置文件方式。端点在内存中使用后立即清除。

**Status**: accepted

**Considered Options**:
- 只支持本地配置：控制台纳管的第一步就要人工登录设备，产品叙事断裂。
- 控制面加密存储：体验最好，但一次泄露即全量凭据暴露，推翻既有 BYOC 决策。

**Consequences**:
- 平台不提供凭据备份或找回；丢失需重新录入。
- 端点离线时无法下发，返回冲突错误而不是排队保存。
- 审计只记录"谁在何时向哪个模块交付了哪类凭据"，不记录值。
